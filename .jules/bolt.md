## 2024-05-13 - [O(N^2) Performance anti-pattern in BrowserPool Cleanup]
**Learning:** The browser pool cleanup routine was modifying a list in-place inside an O(N) loop using `.remove()`, leading to an O(N^2) complexity. This causes significant stalls (e.g. 1.62 seconds down to 0.0005 seconds in benchmarks) when managing larger pools of contexts.
**Action:** When filtering a list, build a new list of retained elements in a single pass O(N) and replace the original list contents in-place using slice assignment (`self.contexts[:] = retained`) to preserve references while avoiding O(N^2) `.remove()` operations.
